       ইউটিউব অটোমেশন ও টেলিগ্রাম বট কমপ্লিট সেটআপ ও ব্যবহারের গাইডলাইন
                    ইউটিউব চ্যানেল: Voice of Prince
=================================================================================

এই অটোমেশন সিস্টেমের মাধ্যমে আপনি টেলিগ্রাম বট দিয়ে স্বয়ংক্রিয়ভাবে:
১. YouTube Shorts লিংক (yt-dlp দিয়ে) অথবা সরাসরি ছবি/ভিডিও নিয়ে রিয়্যাকশন টেমপ্লেট বানাতে পারবেন।
২. "দিস ভিডিও" এবং "মাই রিঅ্যাকশন" টেক্সট কাস্টমাইজ বা ডিফল্ট রাখতে পারবেন।
৩. দুটি ভিডিও হলে যেকোনো একটি অডিও মিউট (Option 1 বা Option 2) করতে পারবেন।
৪. ট্রেন্ডিং/ভাইরাল সাউন্ড লিঙ্ক দিলে ব্যাকগ্রাউন্ডে মিউটে (০%) বা ১%-২% ভলিউমে যুক্ত করতে পারবেন (অ্যালগরিদম বুস্টের জন্য)।
৫. "Voice of Prince" ব্র্যান্ড লোগো/ওয়াটারমার্ক স্বয়ংক্রিয়ভাবে ভিডিওর কর্নারে যুক্ত হবে।
৬. ভিডিও সরাসরি টেলিগ্রাম থেকে "Now" (তাৎক্ষণিক) অথবা "Schedule" (শিডিউল) করে ইউটিউবে আপলোড করতে পারবেন।
৭. অ্যাডমিন সিকিউরিটি: অনুমোদিত অ্যাডমিন ছাড়া অন্য কেউ বট ব্যবহার করতে পারবে না।

---------------------------------------------------------------------------------
[১] সাধারণ ব্যবহার ও রান করার নিয়ম:
---------------------------------------------------------------------------------
- প্যাকেজ অলরেডি ইনস্টল থাকলে:
  সরাসরি "run.bat" ফাইলে ডাবল ক্লিক করুন। বট চালু হয়ে যাবে।

- টেলিগ্রাম বটে যান:
  ১. বটে গিয়ে মেসেজ দিন: /start অথবা /create
  ২. বট আপনাকে স্টেপ বাই স্টেপ প্রশ্ন করবে:
     - স্টেপ ১: উপরের টেক্সট (বাটনে চাপলে ডিফল্ট "This video.!" বসবে, অথবা আপনি লিখে দিতে পারেন)।
     - স্টেপ ২: উপরের ভিডিও বা ছবির YouTube লিংক দিন (অথবা সরাসরি ভিডিও ফাইল/ছবি পাঠান)।
     - স্টেপ ৩: নিচের রিঅ্যাকশন টেক্সট (বাটনে চাপলে ডিফল্ট "My Reaction.!" বসবে)।
     - স্টেপ ৪: নিচের রিঅ্যাকশনের ছবি বা YouTube ভিডিও লিংক দিন।
     - স্টেপ ৫: দুটি ভিডিও হলে বাটন আসবে:
               [ 🔇 উপরের ভিডিও মিউট ] বা [ 🔇 নিচের ভিডিও মিউট ] বা [ 🔊 উভয় সাউন্ড ]
     - স্টেপ ৬: আপলোড অপশন:
               [ ⚡ Now ] -> এখনই চ্যানেলে পাবলিক হয়ে যাবে।
               [ ⏰ Schedule ] -> ১ ঘণ্টা, ৩ ঘণ্টা, ৫ ঘণ্টা পর, কাল সকাল ৯টায় অথবা নির্দিষ্ট সময় লিখে দিতে পারবেন।
               [ 🎬 Only Preview ] -> ইউটিউবে আপলোড না করে শুধু তৈরি হওয়া ভিডিও দেখতে পারবেন।
  ৩. ভিডিও তৈরি হয়ে স্বয়ংক্রিয়ভাবে টেলিগ্রামে চলে আসবে এবং ইউটিউব লিংক দিয়ে দিবে।

[২] উইন্ডোজ RDP (নতুন ডিভাইসে) চালানোর নিয়ম:
---------------------------------------------------------------------------------
- আপনি যখন কোনো নতুন Windows RDP বা পিসিতে এই ফোল্ডারটি নিয়ে যাবেন:
  ১. শুধু "setup_rdp.bat" ফাইলে ডাবল ক্লিক করুন।
  ২. এটি স্বয়ংক্রিয়ভাবে:
     - পাইথন চেক করবে এবং না থাকলে ব্যাকগ্রাউন্ডে ইনস্টল করবে।
     - FFmpeg চেক করবে এবং রেডি করবে।
     - সমস্ত প্রয়োজনীয় পাইথন লাইব্রেরি (requirements.txt) ইনস্টল করবে।
     - yt-dlp লেটেস্ট ভার্সনে আপডেট করবে।
     - বট চালু করে দিবে।
- পরবর্তী সময়ে RDP রিস্টার্ট দিলে শুধু "run.bat" দিলেই চলবে।

[৩] ইউটিউব চ্যানেল ("রহমত ওয়াইটি") কানেক্ট করার নিয়ম:
---------------------------------------------------------------------------------
ইউটিউবে স্বয়ংক্রিয়ভাবে আপলোড ও শিডিউল করার জন্য Google Cloud থেকে একবার পারমিশন নিতে হয়। 
খুব সহজ ৪টি ধাপ:

ধাপ ১: Google Cloud Console প্রজেক্ট তৈরি:
  ১. ব্রাউজারে যান: https://console.cloud.google.com/
  ২. আপনার যে জিমেইলে "Voice of Prince" চ্যানেল আছে সেই জিমেইল দিয়ে লগইন করুন।
  ৩. উপরে "Select a project" -> "New Project" এ ক্লিক করে একটি নাম দিন (যেমন: RohmotAutomation) এবং Create করুন।

ধাপ ২: YouTube API চালু করা:
  ১. বাম পাশের মেনু থেকে "APIs & Services" -> "Library"-তে যান।
  ২. সার্চ বক্সে লিখুন: "YouTube Data API v3"
  ৩. এটিতে ক্লিক করে "Enable" বাটনে চাপুন।

ধাপ ৩: Credentials (OAuth 2.0) তৈরি:
  ১. বাম মেনু থেকে "APIs & Services" -> "OAuth consent screen"-এ যান।
  ২. "External" সিলেক্ট করে Create করুন।
  ৩. App name দিন (যেমন: Rohmot Bot), User support email দিন এবং Save & Continue চাপুন।
  ৪. "Scopes"-এ গিয়ে Save & Continue চাপুন।
  ৫. "Test users"-এ গিয়ে "ADD USERS"-এ আপনার চ্যানেলের জিমেইলটি যোগ করুন এবং Save করুন।
  ৬. এবার বাম পাশের "Credentials" মেনুতে যান।
  ৭. উপরে "+ CREATE CREDENTIALS" -> "OAuth client ID" সিলেক্ট করুন।
  ৮. Application type নির্বাচন করুন: "Desktop app"
  ৯. Name দিয়ে Create করুন।
  ১০. স্ক্রিনে পপআপ আসবে, সেখানে "DOWNLOAD JSON" বাটনে ক্লিক করে ফাইলটি নামিয়ে নিন।
  ১১. ডাউনলোড করা ফাইলের নাম পরিবর্তন করে "client_secrets.json" রাখুন এবং এই ফোল্ডারে ("Islamic Video") পেস্ট করুন।

ধাপ ৪: প্রথমবার লগইন (One-Time Login) ও RDP-র জন্য পোর্টেবিলিটি:
  ১. আপনার নিজের পিসিতে টার্মিনালে রান করুন:
     python youtube_uploader.py
  ২. ব্রাউজারে আপনার গুগল অ্যাকাউন্ট সিলেক্ট করে পারমিশন দিয়ে দিন।
  ৩. পারমিশন দেওয়া মাত্রই আপনার ফোল্ডারে স্বয়ংক্রিয়ভাবে একটি "token.json" ফাইল তৈরি হবে।

[★] RDP-তে ট্রান্সফার করার সুবিধা (কোনো নতুন লগইন ছাড়াই):
---------------------------------------------------------------------------------
- আপনি যখন নিজের পিসিতে একবার লগইন করে "token.json" তৈরি করে ফেলবেন, তখন এই পুরো 
  "Islamic Video" ফোল্ডারটি (যেখানে client_secrets.json এবং token.json রয়েছে) জিপ 
  করে RDP-তে কপি করে নিবেন।
- RDP-তে আর কোনোভাবেই নতুন করে ব্রাউজারে লগইন করতে হবে না! 
- "token.json"-এর ভেতর সুরক্ষিত Refresh Token থাকে, যার ফলে RDP-তে বটটি নিজ থেকেই 
  ইউটিউবে ভিডিও আপলোড ও শিডিউল করে ফেলবে।
